# Product Requirements Document (PRD)
**Product Name:** Tonal Zone Color Picker
**Document Status:** V2 - Math Refinement
**Target Audience:** UI/UX Designers, Graphic Designers, Web Developers

---

## 1. Overview & Objective
Designers often waste time manually hunting for the perfect shade within standard color pickers. This tool leverages the **HSL (Hue, Saturation, Lightness)** color space to divide the gradient into 5 distinct, mathematically constrained tonal zones, allowing for rapid selection based on aesthetic mood.

---

## 2. Key Features & Requirements

### 2.1 Pure HSL Color Engine
*   **Requirement:** The core rendering and selection engine must operate exclusively in HSL. Standard HSV mapping must not be used for the 2D canvas.

### 2.2 The Cartesian Saturation/Lightness Grid
*   **Requirement:** The 2D canvas must map X and Y coordinates strictly to HSL percentages.
*   **X-Axis:** Represents Saturation (0% far left, 100% far right).
*   **Y-Axis:** Represents Lightness (100% top, 0% bottom).

### 2.3 The 5 Tonal Zones (Strict Boundaries)
*   **Requirement:** The canvas is segmented into 5 distinct clickable areas. The draggable selector node must be confined to the active area's coordinates.
*   **Zone Definitions & Boundaries:**
    *   **Zone 1: Pastel:** Saturation `30-100%` | Lightness `75-95%`
    *   **Zone 2: Fresh:** Saturation `50-100%` | Lightness `60-75%`
    *   **Zone 3: Neon:** Saturation `75-100%` | Lightness `45-60%`
    *   **Zone 4: Darken:** Saturation `50-100%` | Lightness `25-45%`
    *   **Zone 5: Somber:** Saturation `30-100%` | Lightness `5-25%`

---

## 3. User Flow
1.  **Select Hue:** Adjust a 0-360 degree slider.
2.  **Choose Zone:** Click one of the 5 predefined Tonal Zones to snap the selector to that specific aesthetic.
3.  **Fine-tune:** Drag the selector node. It will physically hit a "wall" if attempting to drag outside the active zone's bounds.
4.  **Export:** Copy the resulting HSL, HEX, or RGB values.
